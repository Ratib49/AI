HOW TO PUT THIS ON GITHUB (steps 1 and 2 of the roadmap)
=========================================================

1. Go to github.com -> Sign up -> use your STUDENT email.
2. Click "+" (top right) -> New repository
   Repository name: AI
   Public -> do NOT tick "Add a README" (we already have one) -> Create repository

Option A - upload in the browser (easiest)
   On the new empty repo page click "uploading an existing file".
   Open this AI folder, select everything inside it, drag it onto the page.
   (Drag folders too - GitHub keeps the folder structure.)
   Write a message like "Add AI assignment" -> Commit changes.

Option B - from VS Code terminal (needs Git installed: git-scm.com)
   cd path\to\AI
   git init
   git add .
   git commit -m "Add AI assignment"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/AI.git
   git push -u origin main

Steps 5-6 (VS Code): Install Python 3.11/3.12/3.13 from python.org (tick "Add to PATH"),
install VS Code + the Python extension, then File -> Open Folder -> pick this AI folder,
open Test.py and press Run. Turn on File -> Auto Save.

Step 7 (Colab): colab.research.google.com -> File -> Upload notebook ->
bfs_traversal/BFS_Traversal.ipynb -> Runtime -> Run all.
